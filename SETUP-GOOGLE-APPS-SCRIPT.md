## Шаг 1: Подготовка Google Sheets таблицы

### 1.1. Открой свою таблицу
Твоя таблица: https://docs.google.com/spreadsheets/d/1GNOWlGoM5sbrKSvopmLZ4xetjxJQqwD09a6fESGzWnU/edit

### 1.2. Настрой заголовки столбцов

Перейди на первый лист и убедись, что первая строка содержит такие заголовки (в таком порядке):

| A | B | C | D | E | F | G | H | I |

Убедись, что лист называется `Registrations` (внизу вкладка). Если называется по-другому - переименуй или измени в коде.

## Шаг 2: Создание Google Apps Script проекта

### 2.1. Открой Apps Script редактор

Находясь в таблице, в меню выбери:
```
Расширения → Apps Script
```

Откроется новое окно с редактором кода.

### 2.2. Замени код

1. Удали весь текст в редакторе (обычно там `function myFunction() { }`)
2. Скопируй **ВЕСЬ** код из файла `google-apps-script.js` (который я только что создал)
3. Вставь его в редактор Apps Script
4. Нажми **Ctrl+S** (или Cmd+S на Mac) для сохранения

### 2.3. Назови проект

Вверху слева нажми "Untitled project" и переименуй в:
```
ComplexBar Registration Handler
```

---

## Шаг 3: Деплой Web App

### 3.1. Нажми кнопку "Deploy" (Развернуть)

Вверху справа найди синюю кнопку **"Deploy"** → **"New deployment"** (Новое развертывание)

### 3.2. Настрой параметры деплоя

1. **Тип**: Выбери ⚙️ значок → **Web app** (Веб-приложение)

2. **Description** (Описание): 
   ```
   ComplexBar Registration v1
   ```

3. **Execute as** (Выполнять от имени):
   ```
   Me (твой email)
   ```

4. **Who has access** (Кто имеет доступ):
   ```
   Anyone (Все пользователи)
   ```
   
   ⚠️ **Важно!** Выбери именно "Anyone", иначе форма не будет работать!

5. Нажми **"Deploy"**

### 3.3. Подтверди доступ

Появится окно с предупреждением:

1. Нажми **"Authorize access"** (Авторизовать доступ)
2. Выбери свой Google аккаунт
3. Появится предупреждение "Google hasn't verified this app"
4. Нажми **"Advanced"** (Дополнительно) внизу слева
5. Нажми **"Go to ComplexBar Registration Handler (unsafe)"**
6. Прокрути вниз и нажми **"Allow"** (Разрешить)

### 3.4. Скопируй Web App URL

После деплоя появится окно с **Web app URL**. Он выглядит примерно так:

```
https://script.google.com/macros/s/AKfycby.../exec
```

**⚠️ СКОПИРУЙ ЭТОТ URL! Он понадобится на следующем шаге!**

## Шаг 4: Настройка сайта

### 4.1. Открой файл конфигурации

Открой файл: `src/js/events-config.js`

### 4.2. Вставь URL

Найди строку:
```javascript
googleAppsScriptUrl: 'YOUR_GOOGLE_APPS_SCRIPT_URL_HERE'
```

Замени `YOUR_GOOGLE_APPS_SCRIPT_URL_HERE` на скопированный URL:

```javascript
googleAppsScriptUrl: 'https://script.google.com/macros/s/AKfycby.../exec'
```

**Важно:** URL должен быть в кавычках!

### 4.3. Сохрани файл

Сохрани изменения (Ctrl+S / Cmd+S).

## Шаг 5: Сборка и тестирование

### 5.1. Собери проект

В терминале выполни:
```bash
npm run build
```

### 5.2. Запусти dev-сервер

```bash
npm start
```

### 5.3. Протестируй форму

1. Открой сайт в браузере (обычно `http://localhost:8080`)
2. Прокрути вниз до формы регистрации
3. Заполни все поля:
   - Имя: `Тест Тестов`
   - Заведение: `Test Bar`
   - Должность: `Бармен`
   - Телефон: `+7 999 123 4567`
   - Email: `test@example.com`
4. Поставь галочку согласия
5. Нажми **"Зарегистрироваться"**

### 5.4. Проверь результат

**На сайте:**
- Должно появиться зеленое сообщение "Регистрация успешно оформлена!"
- Форма должна очиститься

**В Google Sheets:**
1. Открой свою таблицу
2. Обнови страницу (F5)
3. В последней строке должна появиться новая запись с тестовыми данными!

## 🛡️ Защита от спама

В систему встроена многоуровневая защита от спама и злоупотреблений:

### 1. Rate Limiting (Ограничение частоты запросов)
- **Серверная защита**: Максимум 10 запросов в минуту на весь скрипт
- Защищает от массовых автоматических отправок
- Настраивается в `google-apps-script.js`:
  ```javascript
  RATE_LIMIT: {
    MAX_REQUESTS_PER_MINUTE: 10,  // Измени на нужное значение
    CACHE_DURATION: 60 // секунды
  }
  ```

### 2. Проверка дубликатов
- **Серверная проверка**: Блокирует повторную регистрацию по телефону или email
- Проверка производится только для конкретного мероприятия (eventId)
- Номера телефонов нормализуются (удаляются все символы кроме цифр)
- Email проверяется без учета регистра

### 3. Client-side Cooldown (Таймаут на клиенте)
- **Клиентская защита**: Блокировка формы на 60 секунд после успешной отправки
- Кнопка отправки показывает обратный отсчет
- Состояние сохраняется в localStorage (работает даже после перезагрузки страницы)
- Защищает от случайных повторных отправок

### 4. Honeypot Field (Ловушка для ботов)
- **Двухуровневая проверка**:
  - Клиентская: Форма не отправляется, если поле заполнено
  - Серверная: Запрос отклоняется на уровне Apps Script
- Скрытое поле `website`, невидимое для пользователей
- Боты обычно заполняют все поля автоматически и попадают в ловушку

### Как это работает вместе?

1. **Бот пытается отправить форму** → Попадает в honeypot (заполняет скрытое поле) → Отклонено
2. **Массовая атака** → Rate limiting (более 10 запросов/мин) → Отклонено
3. **Повторная регистрация** → Проверка дубликатов (телефон/email уже есть) → Отклонено
4. **Случайные двойные клики** → Client-side cooldown (60 сек блокировка) → Предотвращено

## 🔧 Дополнительные настройки

### Добавление нового мероприятия

Чтобы добавить новое мероприятие:

1. **Создай новую таблицу** на Google Drive
2. **Настрой заголовки** (как в Шаге 1.2)
3. **Открой Apps Script** в новой таблице
4. **Скопируй тот же код** `google-apps-script.js`
5. **Измени SPREADSHEET_ID** на ID новой таблицы
6. **Задеплой** как Web App
7. **Добавь в конфиг** `src/js/events-config.js`:

```javascript
export const EVENTS_CONFIG = {
  'complexbar-001': {
    eventId: 'complexbar-001',
    title: 'Complex Bar Collection',
    registrationEnabled: true,
    googleAppsScriptUrl: 'https://script.google.com/.../exec'
  },
  'new-event-002': {  // ← Новое мероприятие
    eventId: 'new-event-002',
    title: 'Новое мероприятие',
    registrationEnabled: true,
    googleAppsScriptUrl: 'https://script.google.com/.../exec'  // ← Другой URL
  }
};
```

### Изменение Rate Limit

В коде Apps Script найди:
```javascript
RATE_LIMIT: {
  MAX_REQUESTS_PER_MINUTE: 10,  // ← Измени на нужное значение
  CACHE_DURATION: 60
}
```

### Отключение регистрации

В `src/js/events-config.js` измени:
```javascript
registrationEnabled: false  // ← Было true
```

## 🐛 Решение проблем

### Ошибка "Регистрация временно недоступна"

**Причина:** URL Google Apps Script не настроен.
**Решение:** Убедись, что ты выполнил Шаг 4 и вставил правильный URL.

### Ошибка 403 или "Not authorized"

**Причина:** Неправильные настройки доступа в Apps Script.
**Решение:** 
1. Открой Apps Script
2. Deploy → Manage deployments
3. Нажми ✏️ (Edit) рядом с текущим деплоем
4. Убедись, что "Who has access" = **"Anyone"**
5. Deploy как новую версию

### Данные не появляются в таблице

**Причина:** Неправильное название листа или SPREADSHEET_ID.
**Решение:**
1. Проверь, что лист называется `Registrations`
2. Проверь SPREADSHEET_ID в коде Apps Script
3. Убедись, что заголовки в первой строке

### CORS ошибка в консоли браузера

**Причина:** Apps Script не задеплоен как Web App.
**Решение:** Повторно выполни Шаг 3 - Deploy as Web App.
